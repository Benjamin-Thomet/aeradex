# Sicherheit

aeradex verwaltet Buchhaltungs- und Lohndaten. Sicherheitslücken bitte **nicht** als öffentliches Issue melden,
sondern vertraulich:

- über GitHub: Reiter **Security → Report a vulnerability** (private Meldung an die Maintainer), oder
- per E-Mail an [info@aeradex.ch](mailto:info@aeradex.ch).

Bitte beschreiben, wie sich das Problem nachstellen lässt — mit einem Testbuch (`aeradex init` in einem
Temp-Ordner), nie mit echten Buchhaltungsdaten. Wir bestätigen den Eingang innert weniger Tage und melden uns,
sobald eine Korrektur bereitsteht.

Unterstützt wird jeweils die neueste veröffentlichte Version.
