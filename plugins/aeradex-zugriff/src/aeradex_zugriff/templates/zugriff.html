Einrichten auf dem PC

Windows: install.ps1 -Server {{ s.server }} -Benutzer {{ s.benutzer }} -Url <Adresse dieses Buchs> aus plugins/aeradex-zugriff/windows ausführen; den ausgegebenen Schlüssel oben eintragen.

Linux/Mac: Schlüssel erzeugen, oben eintragen, dann SSH und Claude Code verbinden:

ssh-keygen -t ed25519 -f ~/.ssh/{{ s.alias }} -N "" -C "$(whoami)-buchhaltung"
cat ~/.ssh/{{ s.alias }}.pub
printf 'Host {{ s.alias }}\n    HostName {{ s.server }}\n    User {{ s.benutzer }}\n    IdentityFile ~/.ssh/{{ s.alias }}\n    IdentitiesOnly yes\n' >> ~/.ssh/config
claude mcp add --scope user aeradex -- ssh {{ s.alias }} mcp
